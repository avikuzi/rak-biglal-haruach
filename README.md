# רק בגלל הרוח 🏄‍♂️💨
תחזית Wingfoil שבועית לחופי ישראל (שדות ים, בת גלים, תל ברוך וספוטי הכנרת).

## מאפיינים מרכזיים
- **התאמה אישית לפי רמת גולש:** מחדד (7–12 קשר), מרחף (11–18 קשר), מהפכים (14 קשר ומעלה, משבים מותרים). גודל הכנף לא מגדיר רמה; ההמלצה בטבלה מחושבת לפי הרוח הצפויה. ערך שמור ישן (מתחיל, בינוני, מתקדם) עובר לרמה החדשה. ברירת המחדל למבקר חדש: מחדד.
- **אקורדיון חופים עם חשיפה הדרגתית (Progressive Disclosure):** הצגת תנאי כניסה ובטיחות.
- **התראות מותנות לפי כיוון רוח:** אזהרת Onshore בסלעים בבת גלים, סירת חילוץ בגינוסר ועוד.
- **נגישות:** סרגל לגופן, ניגודיות וניווט מקלדת. אין כאן הצהרת עמידה מאושרת בתקן.
- **חיזוי גודל כנף מומלץ (Wing size).**
- **שלושה מודלים:** ICON (DWD), ECMWF ו-GFS (NOAA) דרך Open-Meteo, בבקשה אחת לכל חוף. בטבלה מוצג חציון, וחלון נספר רק אם לפחות שני מודלים בטווח.
