# רק בגלל הרוח 🏄‍♂️💨
תחזית Wing Foil שבועית חכמה לחופי ישראל (שדות ים, בת גלים, תל ברוך וספוטי הכנרת).

## מאפיינים מרכזיים
- **התאמה אישית לפי רמת גולש:** מתחיל, בינוני, מתקדם — לפי מיומנות במים. גודל הכנף לא מגדיר רמה; ההמלצה בטבלה מחושבת לפי הרוח הצפויה.
- **אקורדיון חופים עם חשיפה הדרגתית (Progressive Disclosure):** הצגת תנאי כניסה ובטיחות.
- **התראות מותנות לפי כיוון רוח:** אזהרת Onshore בסלעים בבת גלים, סירת חילוץ בגינוסר ועוד.
- **נגישות מלאה (תקן ת"י 5568 / WCAG 2.1 AA):** סרגל נגישות צף, ניווט מקלדת, תמיכה בקוראי מסך, ניגודיות גבוהה והצהרת נגישות.
- **חיזוי גודל כנף מומלץ (Wing size).**
